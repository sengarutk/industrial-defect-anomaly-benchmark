# Industrial Defect Anomaly Benchmark

[![tests](https://github.com/sengarutk/industrial-defect-anomaly-benchmark/actions/workflows/tests.yml/badge.svg)](https://github.com/sengarutk/industrial-defect-anomaly-benchmark/actions/workflows/tests.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

A reproducible benchmark of three unsupervised visual anomaly detectors (PatchCore-style, PaDiM-style,
convolutional autoencoder) on seven MVTec AD categories, evaluated beyond AUROC: corruption robustness,
operating points under false-alarm budgets with thresholds that never see the test set, and
cost-calibrated threshold selection measured out of sample.

**Read first:** [Methods and protocol](docs/methods.md) · [Benchmark report](docs/benchmark_report.md)
(generated) · [Data card](docs/data_card.md) · [Environment](docs/environment.md) ·
[Audit and remediation log](docs/AUDIT.md)

What these numbers can and cannot show:

* **Alarm budgets of a few per 1,000 cannot be verified on MVTec AD.** Test sets have 20–58 nominal images,
  so the smallest non-zero false-alarm rate they can express is 17–50 per 1,000. Every rate is reported with
  an exact confidence interval and that resolution.
* **Significance is bounded by the number of categories.** Methods are compared with categories as the
  independent units (seeds are not independent experiments); with 7 categories the smallest attainable
  two-sided Wilcoxon p-value is 0.0156.
* **Baselines are reimplementations** with ResNet-18 at 256 px, not official reproductions.
* Latency and the GPU coreset benchmark are reported only when measured on a GPU (see
  [docs/environment.md](docs/environment.md)).

## Reproduce

```bash
pip install -r requirements.txt
```

```bash
PYTHON=python bash scripts/reproduce_main_results.sh
```

The script downloads and verifies the data, runs the tests, the 63-run sweep (resumable), the operating-point,
CCT, aggregation and failure analyses, the GPU-only measurements when CUDA is present, then builds every
figure, table and the paper assets. Individual steps:

| Step | Script | Output |
|---|---|---|
| Data | `scripts/download_dataset.py` | `data/mvtec_ad/` (validated against the official manifest) |
| Sweep | `scripts/run_benchmark.py` | `results/mvtec_ad/{scores,maps,runs,robustness}/`, `tables/runs_master.csv` |
| Operating points | `scripts/run_operational_eval.py` | `tables/operational_*.csv`, `operator_load.csv`, `significance_cost.csv` |
| CCT | `scripts/run_cct_experiments.py` | `tables/cct_*.csv`, `significance_cct.csv` |
| Aggregation ablation | `scripts/run_ablations.py` | `tables/aggregation_*.csv` |
| Failure cases | `scripts/run_failure_analysis.py` | `figures/failure_cases/`, `tables/failure_cases.csv` |
| Latency (GPU) | `scripts/profile_latency.py` | `tables/latency.csv` |
| Coreset benchmark (GPU) | `scripts/run_coreset_benchmark.py` | `tables/coreset_benchmark.csv` |
| Figures / report | `scripts/generate_figures.py`, `scripts/generate_report.py` | `figures/`, `tables/latex/`, `docs/benchmark_report.md` |
| Paper | `scripts/sync_paper_assets.py --zip` | `overleaf_paper/{tables,figures}/`, `dist/overleaf_package.zip` |

All settings live in `configs/benchmark.yaml` and `configs/operational.yaml`. Image-level score archives
are tracked in git; per-pixel maps (`results/*/maps/`) are regenerated by the sweep.

## Repository layout

```
configs/         benchmark and operational settings (single source of truth)
src/mvtec.py     dataset manifest, validation, loaders, calibration split
src/methods/     PatchCore-style, PaDiM-style, autoencoder, greedy k-center coreset
src/metrics/     image/pixel metrics (exact AU-PRO), operating points, CCT, statistics
src/robustness/  corruptions, cached corrupted test sets, stress test
src/experiments/ CCT protocol, stream projections, aggregation ablation, coreset benchmark
src/benchmarking/, src/analysis/, src/visualization/
scripts/         pipeline entry points (see table above)
tests/           unit, regression and end-to-end tests
overleaf_paper/  manuscript; tables/figures are copied in by sync_paper_assets.py
```
